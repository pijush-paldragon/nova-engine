# UI Text Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Localization, shaped multilingual text (RTL/CJK/complex scripts), wrapping/shrink-to-fit and BBCode rich text with inline icons, for UI labels and world `TextLabel`s, with Brick Breaker shipping in en/de/ja/ar.

**Architecture:** SDL_ttf with its vendored HarfBuzz shapes text and handles fallback fonts, direction and plain wrapping. A new engine-private `TextBlock` replaces the UI's `TextRun` and the world label cache: plain text is one SDL_ttf text object; rich text is parsed into runs and laid out by Nova's own line breaker. `Localization` (public, `text().lang()`) owns language files, plural rules and formatting; a language generation counter makes keyed labels re-render.

**Tech Stack:** C++20 (no exceptions/RTTI), SDL3, SDL3_ttf + HarfBuzz (vendored), yyjson, doctest, Python 3 (tools), fontTools (dev-only, for subsetting test/game fonts).

**Spec:** `docs/superpowers/specs/2026-10-24-ui-text-design.md`

## Global Constraints

- No exceptions/RTTI; zero heap allocations in steady-state gameplay frames. Language load/switch and a label's first layout run inside `memory::LoadingScope`; SDL_ttf calls that allocate internally run inside `memory::DriverAllocScope`.
- Missing keys, fonts, icons or bad markup never crash: dev builds (`NOVA_DEV_TOOLS`) log once, release builds fall back silently.
- Language files and fonts are read through `openAsset`/`Assets`.
- Public headers stay free of SDL/SDL_ttf/HarfBuzz/yyjson.
- Values pinned by the spec: RTL languages `ar he fa ur`; shrink step **2 design px**, default `minScale` **0.6**; default `lineSpacing` **1.0**; ellipsis "…"; missing key shown as `[key]`; save key `language`; dev override env `NOVA_LANG`; font cache key `path@size#lang`; kinsoku no-start `。、，．・：；？！）」』】〕ー`, no-end `（「『【〔`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Switching language while a popup is open or a scene is paused below** must re-render and re-lay out every canvas and world label, not only the top scene's. Test: `Language switch updates every scene's labels` (Task 4).
2. **Placeholder values containing markup or braces** (a player named `[color=red]x` or `{score}`) must render literally. Test: `Placeholder values never inject tags or placeholders` (Task 7).
3. **A label whose text becomes empty, then rich, then plain again** must not leak text objects or keep stale icons. Test: `Label switches between empty, plain and rich text cleanly` (Task 7).
4. **A language file missing plural categories or with a wrong type** (number where a string is expected) must load with a logged message and fall back per key, never crash. Test: `Bad language file entries fall back per key` (Task 2).
5. **Shrink-to-fit on text that can never fit even at minScale** must stop at minScale and truncate/clip, without looping or loading unbounded font sizes. Test: `Shrink stops at minScale` (Task 5).
